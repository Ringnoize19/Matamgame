ตำแหน่งห้องลับ (Backroom Espionage)

อัปเดตเมื่อ: พฤศจิกายน 2026 • หมวดหมู่: ไกด์

ทั่วทั้งแมนฮัตตันจะมีห้องลับนิรภัยซ่อนอยู่ บนแผนที่จะแสดงเป็นไอคอนรูป "?" ให้เราเข้าไปแก้ไขปริศนาเพื่อเปิดห้องลับดังกล่าว
โดยจะมีอยู่ด้วยกันทั้งหมด 6 สถานที่ เมื่อทำครบทุกที่แล้วจะปลดล็อคถ้วยรางวัล Backroom Espionage

The Downtown

ห้องลับแห่งแรกตั้งอยู่ทางทิศเหนือของ Oldest House เป็นร้านกาแฟที่ใช้ชื่อว่า ATLANTIS

เมื่อเข้าไปจะพบกับข้อความบนเคาน์เตอร์บอกว่าเจ้าของร้านชอบเปิดเครื่องใช้ไฟฟ้าตามลำดับ โดยเริ่มจากเครื่องเล็กที่สุดไปจนถึงเครื่องใหญ่ที่สุด

คำแนะนำคือให้ไปเปิดระบบไฟก่อนแล้วเรียงลำดับเครื่องใช้ไฟฟ้าตามนี้:
• วิทยุ (บนผนังด้านตะวันตก)
• เครื่องชงกาแฟบนเคาน์เตอร์สีแดง
• เครื่องชงกาแฟขนาดใหญ่กว่าเล็กน้อยที่วางอยู่บนตู้ด้านหลัง
• เครื่องขายโซดา
• ไมโครเวฟ
• ตู้เย็น

เมื่อทำทุกอย่างแล้วประตูห้องลับจะเปิดออก

The Central

ห้องลับต่อไปตั้งอยู่ทางทิศตะวันออกของ Field Office เป็นร้านซักรีดที่ชื่อว่า WEAR'EM & WASH'EM

เมื่อเข้าไปจะพบกับข้อความบนกระดาน มีแต่เลข 0 กับ 1 ที่น่าปวดหัว

แต่ไม่ต้องตกใจไป มันไม่ได้ยากอย่างที่คิด มันเป็นเพียงการบอกตำแหน่งที่ต้องเปิดเครื่องซักผ้าเท่านั้น:
• 0 0 0 1 0 0 0 คือแถวเครื่องซักผ้าด้านซ้าย (หันหน้าเข้ากระดาน)
• 0 0 1 1 0 0 ตรงข้ามกับเครื่องซักผ้าแถวแรก (กลับหันหลัง)
• 1 0 0 0 0 1 อยู่แถวถัดจากแถวที่สอง (หลังแถวสอง)
• 0 0 0 0 0 0 ไม่มี
• 0 0 0 0 0 0 ไม่มี
• 0 0 0 0 0 0 ไม่มี
• 1 0 0 0 0 0 อยู่ชิดกำแพงด้านขวา (หันหน้าเข้ากระดาน)

เมื่อทำทุกอย่างแล้วประตูห้องลับจะเปิดออก

The Evacuation Zone

ห้องลับอยู่ทางขวาของประตูวาป เป็นหอศิลป์ที่ชื่อว่า KONSTIG

เมื่อเข้าไปจะพบกับข้อความบนเคาน์เตอร์ที่บอกใบ้ให้เราเปิดไฟส่องรูปภาพให้ถูกต้อง

โดยเริ่มจากซ้ายมือ (หันหน้าเข้าหอศิลป์)
• Journey ส่องไฟไปที่รูปตรงกลาง

• Windows ส่องไฟไปที่รูปซ้ายมือ

• Thunder ส่องไฟไปที่รูปซ้ายมือ

• Thunder ส่องไฟไปที่รูปตรงกลาง
เมื่อทำทุกอย่างแล้วประตูห้องลับจะเปิดออก

The Park

ห้องลับอยู่ทางซ้ายล่างของพื้นที่ The Park เป็นคาเฟ่/ร้านอาหารในสวน

เมื่อเข้าไปจะพบกับข้อความบนเคาน์เตอร์บอกใบ้วิธีได้รับรหัสเอาไว้ป้อนลงในเครื่องคิดเงิน ซึ่งรหัสจะตรงกับหมายเลขโต๊ะและสิ่งที่พวกเขาสั่งในเมนู และหากนำไปเทียบกับเมนูก็จะได้รหัส

รหัสลับมีดังนี้:
• โต๊ะที่ 1 ต้องการ Iced Coffee (B)
• โต๊ะที่ 5 ต้องการ The Spiciest Chai (D)
• โต๊ะที่ 4 ต้องการ Espresso (A)
• โต๊ะที่ 2 ต้องการ Caramel Latte (C)

เมื่อทำทุกอย่างแล้วประตูห้องลับจะเปิดออก

The West Incursion Zone

ห้องลับอยู่ทางซ้ายล่างของพื้นที่ The West Incursion Zone เป็นร้านของชำที่ใช้ชื่อว่า URBAN FRESH

ด้านในจะเป็นการไขปริศนาที่เกี่ยวข้องกับเครื่องกดน้ำอัดลม

เริ่มต้นด้วยการทำให้เครื่องกดน้ำอัดลมทำงาน มันจะแสดงไฟกระพริบตามนี้ 3 1 2 1
จากนั้นให้นำไปป้อนเป็นรหัสที่เคาน์เตอร์เก็บเงินด้วยการสลับรหัสเป็น 1 2 1 3

The Unknown

ห้องลับอยู่ตรงกลางของพื้นที่ The Unknown เป็นฟิตเนสที่ใช้ชื่อว่า FULSE FITNESS

เมื่อเข้าไปด้านในให้เข้าไปที่ห้องขวามือจะมีคำใบ้ติดอยู่บนกระดาน

ถ้าอ่านแล้วไม่เข้าใจไม่เป็นไรนะ ผมก็งง แฮร่!!! หยอกน้า ให้เรียงลำดับการใช้งานเครื่องใช้ไฟฟ้าตามนี้:
• เริ่มด้วยเครื่องปั่นจักรยานหน้าร้านปรับให้เป็น 0.5mph
• วิ่งไปที่หลังร้านจะมีเครื่องปั่นจักรยานเหมือนกันให้ปรับเป็น 15mph
• ไปเปิดตู้กดกระป๋องน้ำอัดลมกลางร้าน
• ไปที่เครื่องปั่นจักรยานหน้าร้านแล้วเปลี่ยนเป็น 15mph
• สุดท้ายกลับไปที่เครื่องปั่นจักรยานหลังร้านแล้วเปลี่ยนเป็น 0.5mph
เมื่อทำทุกอย่างแล้วประตูห้องลับจะเปิดออก
